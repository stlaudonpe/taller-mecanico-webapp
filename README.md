# Garage GT - Sistema de Gestión de Taller Mecánico

royecto Integrador - Análisis y Diseño de Sistemas

Este repositorio contiene el análisis, diseño conceptual, modelado y la implementación básica funcional de un sistema web diseñado para administrar las operaciones principales del taller mecánico **"Garage GT"**.

---

Estructura del Repositorio

*   `docs/`: Documentación del proyecto, requerimientos, diagramas UML y modelo de datos.
*   `src/`: Código fuente de la aplicación web (CRUDs de Clientes, Vehículos, Mecánicos y Órdenes).
*   `security/`: Evidencias de análisis estático de seguridad con Semgrep.

---

Tecnologías y Herramientas Utilizadas

*   **Gestión del Proyecto:** Jira Software (Metodología SCRUM)
*   **Diseño y Modelado:** draw.io / dbdiagram.io
*   **Entorno Local:** XAMPP (Apache y MySQL)
*   **Análisis de Seguridad:** Semgrep
*   **Asistentes de IA:** Jules (Google)
